Your phone is the robot's brain

Phone Brain drives OpenForge AX-1: the phone does the seeing and deciding, a small ESP32 bridge moves the motors. No robot yet? Drive the 3D twin: it runs the same protocol and the same safety rules as the real bridge.

    Set up a model (optional)

    Without a model, a built-in parser understands short commands. A local model understands free-form requests. Your words and the robot's joint angles go only to the model server you enter here, on your own computer. Nothing is sent to us.

    • Ollama (http://localhost:11434): install it, then run ollama pull qwen2.5:3b. A page opened from localhost works as is. For any other site, set the environment variable OLLAMA_ORIGINS to this page's address () and restart Ollama.
    • LM Studio (http://localhost:1234): load a model, open the Developer tab, press Start Server, and turn on CORS.
    • llama.cpp (http://localhost:8080): start it with llama-server --jinja -m your-model.gguf. The --jinja flag turns on tool calling.

    Use an instruct model that can call tools, 3B or larger: Qwen2.5 3B or 7B Instruct, or Llama 3.2 3B Instruct. Smaller models often ignore the tools. Chrome may ask to allow this page to reach a service on your device: that is your own model server.
